# Agent Skills

Use the smallest applicable skill, and read its `SKILL.md` before starting that class of work.

| Skill | Use for |
|---|---|
| `research-to-architecture-atlas` | Researching standards/frameworks and building a source-grounded interactive atlas. |
| `deep-research` | Any task requiring external facts, source comparison, or current documentation. |
| `workflow-composer` | Five or more independent comparable research items, loops, or explicit parallel/comprehensive research. |
| `webdev-readme-fullstack` | Full-stack React/Express/database/storage implementation conventions. |

| `skill-creator` | Creating or modifying a reusable Manus skill. |

## Routing rules

- Read `deep-research` before searching or fetching external sources.
- Read `research-to-architecture-atlas` for architecture/modeling standards, metamodels, comparison atlases, or source-backed visual research.
- Use `workflow-composer` when the work contains five or more independent comparable research units or explicit fan-out requirements.
- Read `webdev-readme-fullstack` before changing schema, server routes, authentication, or database-backed storage.
- Read `webdev-file-storage` before implementing or hardening object-storage upload/delete flows.
- Read `skill-creator` before modifying any skill; validate with its official validator.
- Read `manus-config` before saving shared project files, connectors, agent profiles, or schedules.
- Use `image-processing` for deterministic inspection/transformation of existing assets; use `imagegen` for original visual assets.
- Use `office`/`office-documents` for document artifacts; use `slides` for any presentation work.
- Keep repository instructions implementation-specific; keep reusable domain workflow in the skill package.
