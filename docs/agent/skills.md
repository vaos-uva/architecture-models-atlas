## Skill selection rules

- Read research guidance before searching or fetching external sources.
- Read the full-stack guidance before changing schema, server routes, authentication, or storage.
- Read `skill-creator` before modifying any skill; validate with its official validator.
- Do not invent a new process when an installed skill already covers the task.
- Keep repository instructions implementation-specific; keep reusable domain workflow in the skill package.
