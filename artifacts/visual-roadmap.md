# KNIGA Visual Roadmap

## Stage 0 — Foundation

Canonical terms, source/claim provenance, stable IDs, model/view definitions, baseline export, parity tests, and header identity.

## Stage 1 — Trustworthy graph

Typed nodes and edges, evidence labels, edge rationale, search/filter, selected-node detail, keyboard fallback, deep links, and a synchronized glossary/comparison panel.

## Stage 2 — Configuration-driven views

One canonical model feeds glossary, registry, comparison table, graph, guided path, artifact diagram, and timeline. View definitions declare scope, locale, filters, derivation, and omissions.

## Stage 3 — Multilingual experience

Separate UI translations from research translations. Preserve source labels and edition wording. Add English/Russian fallback, translation status, localized search, and long-label responsive checks.

## Stage 4 — Historical and evidence views

Claim panels, source locations, edition diffs, change history, derived metrics with formulas, and visible uncertainty. Every chart states what it does not prove.

## Stage 5 — Saved/shareable views

Versioned URLs, saved filters, canonical JSON/CSV export, large-graph progressive disclosure, performance checks, and contributor/reviewer workflows only after read-only contracts stabilize.

## Visual grammar

Use shape and text as well as color. Distinguish source claim, normalized concept, mapping, synthesis, and derived metric through labels, icons, legends, and accessible text. Visual richness must reveal relationships, not decorate duplicated facts.
